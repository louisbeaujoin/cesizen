entrypoint.sh — démarrage automatique

# .env absent → copie le modèle (secrets hors image)
[ ! -f .env ] && cp .env.example .env

# Génère la clé applicative
[ -z "$APP_KEY" ] && php artisan key:generate --force

# Attend MySQL puis migre
until php artisan migrate --force; do
  sleep 3
done

# Seeder si demandé
if [ "${DB_SEED:-false}" = "true" ]; then
  php artisan db:seed --force
fi
exec apache2-foreground

Plan de sécurisation : prévention et chiffrement

Grille : Sécurité — plan complet 8/15

Prévention des risques

  • SecurityHeadersMiddleware : 5 en-têtes HTTP (CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy)
  • Throttle 5,1 : blocage brute-force → HTTP 429
  • Cast (int) XSS : paramètres URL dans BreathingController
  • Eloquent ORM : requêtes préparées PDO (SQL injection)
  • @csrf : token sur tous les formulaires POST
  • Middleware auth + rôles : admin vs user
  • APP_DEBUG=false : aucune trace en production

Tests de sécurité automatisés

Grille : Sécurité — qualité du code 9/15

4 tests dans tests/Feature/SecurityTest.php prouvent que les mécanismes fonctionnent en CI :

// Test 1 — 5 en-têtes HTTP de sécurité sur toutes les pages (dont CSP)
test('security headers are present on home page', function () {
    $this->get('/')->assertHeader('X-Content-Type-Options', 'nosniff')
                   ->assertHeader('Content-Security-Policy');
});

// Test 2 — CSP bloque les ressources externes
test('content security policy blocks external sources', function () {
    $csp = $this->get('/')->headers->get('Content-Security-Policy');
    expect($csp)->toContain("default-src 'self'")->toContain("object-src 'none'");
});

// Test 3 — HTTP 429 après 5 tentatives de connexion
test('throttle middleware blocks after 5 login attempts', function () {
    for ($i = 0; $i < 5; $i++) { $this->post('/connexion', [...]); }
    $this->post('/connexion', [...])->assertStatus(429);
});

// Test 4 — XSS neutralisé par cast (int) dans BreathingController
test('xss cast int protection on breathing page', function () {
    $this->get('/respiration?inspiration=5%3Balert(1)%2F%2F')
         ->assertStatus(200)->assertDontSee('alert(1)', false);
});
